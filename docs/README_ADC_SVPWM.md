# v3 update: raw ADC telemetry + sensorless SVPWM mode 4

This update extends the USART3-only / BOARD 0 firmware.

## Control modes

- `1 = VLT`
- `2 = SPD`
- `3 = TRQ`
- `4 = SVPWM` (sensorless open-loop)

`SVPWM 4` does not use Hall/rotor-position feedback to generate PWM. The generated BLDC controller is bypassed only for mode 4 because its control-mode input supports modes 0..3. The open-loop electrical angle is generated by a Q16 phase accumulator and a Q15 sine LUT, followed by centered common-mode injection (continuous SVPWM).

Default sensorless tuning in `Src/config.h`:

- `SVPWM_POLE_PAIRS = 15`
- `SVPWM_MIN_MOD_PERMILLE = 120`
- `SVPWM_MAX_MOD_PERMILLE = 850`

At `N_MOT_MAX=1000 rpm`, `PWM_FREQ=16000`, and 15 pole-pairs, command magnitude 1000 corresponds to about 250 electrical Hz.

Safety retained/added in mode 4:

- USART3 command timeout
- motor enable interlock
- DC-link current chopping (`I_DC_MAX`)
- phase-current chopping (`I_MOT_MAX`), including reconstructed third phase
- bridge MOE disabled at zero SVPWM command
- battery/temperature/poweroff logic

Because mode 4 is open-loop and has no rotor feedback, RPM telemetry is intentionally reported as 0 in mode 4. The command controls electrical rotation frequency/amplitude, not closed-loop measured speed.

## Telemetry frame

Six raw ADC DMA samples were appended to `SerialFeedback`:

- `dcl = adc_buffer.dcl`
- `rla = adc_buffer.rlA`
- `rlb = adc_buffer.rlB`
- `dcr = adc_buffer.dcr`
- `rrb = adc_buffer.rrB`
- `rrc = adc_buffer.rrC`

The checksum includes all six ADC words. The binary feedback frame is now 42 bytes, so firmware and `tools/hoverserial.py` must be updated together.

Python telemetry is intentionally compact:

```text
cmd=0,50 rpm=49,-51 V=42.54 T=44.2C cycle=2705 dcl=2000 rla=2001 rlb=1999 dcr=2002 rrb=2003 rrc=1998
```

## Python use

```bash
python3 tools/hoverserial.py
```

Default port is `/dev/ttyUSB0`, baud `115200`.

Interactive mode selection accepts either:

```text
mode 1
mode 2
mode 3
mode 4
```

or simply:

```text
1
2
3
4
```

The Python tool forces a zero drive command before changing `CTRL_MOD`.
